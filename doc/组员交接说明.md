# 组员交接说明

## 打开工程

1. 安装 Unity 6000.4.0f1，并在 Unity Hub 中用 Add project from disk 添加本目录。
2. 首次打开会重新导入资源，约三到五分钟，等待右下角进度条结束。
3. 打开 `Assets/Scenes/Main.unity`，点击顶部播放按钮运行。
4. 进入游戏后选择「离线演示模式」，再点击 Game 窗口锁定鼠标。

## 修改位置

- 主要逻辑与界面：`Assets/Scripts/KitchenSimulator.cs`
- 场景：`Assets/Scenes/Main.unity`
- 着色器：`Assets/Shaders/`
- 命题文档与图：`doc/`
- 任务分工计划：`D:\Word\赛前任务分工与交付计划.docx`

## 当前状态

- 天空为纯色昼夜变化，桌面端运行自动锁定 1920×1080。
- 住宅分为 A 一室一厅一卫一厨、B 两室两厅一卫一厨、C 三室两厅两卫一厨，各有独立走廊。
- 家具已加入倒角、圆桌、床腿、软包扣、沙发腿、搭毯、床头灯、地毯、踢脚线、天花板和石膏线。
- 本次只分发源码，不含 WebGL 网页构建，也不含 `Library`、`Temp`、`Logs`、`.git`。
- 需要运行包时，在 Unity 编辑器中使用 `Kitchen > Build WebGL` 或 Build Settings 出 Windows 版，不要用命令行批处理。

| `WASD` / `Shift` | 移动 / 加速 |

| `T` | 数字孪生监测平台 |
| `K` | 维修知识手册 |
| `F` | 开关门窗 |
| `V` | 第一 / 第三人称切换 |
| `M` | 小地图 / 大地图 / 收起 |

## 注意

- 不要在界面、PPT 或文档中出现学校、姓名、队名与仓库地址。
- 启动页的赛项编号占位符需要在赛前替换为现场编号。
