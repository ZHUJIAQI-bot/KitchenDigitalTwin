# 数字孪生驱动的老旧住宅厨房改造数字化平台

> 🎮 **在线体验（网页版，无需安装）**：https://zhujiaqi-bot.github.io/KitchenDigitalTwin/

## 一、项目定位（二元结构主题）

**数字孪生技术　+　老旧住宅厨房改造工程**

面向城市更新中大量存在的老旧住宅厨房，把每个隐患点位建成带传感器的**数字孪生体**，用实时数据驱动隐患排查与改造决策，替代传统人工巡检"靠经验、易漏检"的模式。

## 二、工程问题

老旧住宅厨房改造长期依赖人工巡检：隐患依靠经验判断、缺少量化数据、漏检率高、处置过程不可追溯。典型隐患（渗漏、燃气泄漏、电气老化、结构空鼓等）在早期均有可量化的物理表征，但缺乏持续监测手段。

## 三、技术路径

```
传感器实时采集 → 数字孪生模型比对阈值 → 异常报警 → 现场核查施工 → 数据回归正常 → 验收报告归档
```

系统内置 15 类工程隐患，每类对应一个真实工程传感器：

| 隐患 | 传感器 | 单位 | 报警阈值 |
|---|---|---|---|
| 水槽下方渗漏 | 柜内湿度 | %RH | > 80 |
| 灶台燃气管老化 | 可燃气体浓度 | %LEL | > 10 |
| 冰箱插座接触不良 | 插座温升 | ℃ | > 55 |
| 地面 / 墙面瓷砖空鼓 | 空鼓率 | % | > 15 |
| 沙发背景墙开裂 | 裂缝宽度 | mm | > 1.5 |
| 墙面返潮发霉 | 墙体含水率 | % | > 18 |
| 地漏返味 | 硫化氢浓度 | ppm | > 5 |
| 电视线缆外露 | 线缆表面温度 | ℃ | > 60 |
| 木门变形关不严 | 门缝宽度 | mm | > 4 |
| 马桶底座渗水 | 底座渗漏量 | mL/h | > 20 |

**改造完成后，对应传感器读数自动回落至正常区间** —— 这是数字孪生"数据闭环"的直接证据。

## 四、关键指标（KPI）与对比分析

平台实时统计本方案指标，并与传统人工巡检基准对比：

| 指标 | 本平台（数字孪生） | 传统人工巡检 |
|---|---|---|
| 隐患消除率 | 实时统计 | 68 % |
| 平均处置时长 | 实时统计 | 26 h |
| 漏检率 | 3 % | 32 % |
| 改造成本 | 实时统计 | ×1.28 |

## 五、系统输出

- **数字孪生监测平台**（`T`）：现场传感器实时数据表 + KPI 对比分析
- **验收报告**（监测平台内一键导出）：自动生成含隐患清单、处置记录、KPI 对比与结论的文本报告，并下载到本地

## 六、操作方式

| 键 | 功能 |
|---|---|
| `T` | 数字孪生监测平台（默认打开） |
| `WASD` / `Shift` | 移动 / 加速 |
| **鼠标左键** | 现场施工（连点推进） |
| `Q` / 滚轮 | 切换工具（不同隐患需专用工具） |
| `G` | 商店（工具店 / 服装店） |
| `B` | 工具包 |
| `N` | 日历 · 任务单 · 账目本 |
| `M` | 地图放大 / 缩小 |
| `E` | 对话 / 与同事交流 |
| `F` | 开关房门 |
| `空格` | 跳跃 |
| `R` | 夜间休息 |
