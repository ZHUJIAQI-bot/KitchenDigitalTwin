# 焕新厨房：老旧住宅厨房改造数字化仿真原型

这是一个面向工程场景数字化展示的社区调度 Unity 原型。玩家从上帝视角管理 6 户住宅的厨房改造任务，发现问题、安排维修人员、控制项目预算并查看维修进度。

## 打开方式

使用 Unity `6000.4.0f1` 打开本目录：

`D:\Codex\2026-09-15\gei\KitchenDigitalTwin`

打开 `Assets/Scenes/Main.unity` 后点击 Play。

如果场景没有自动出现，可以在菜单执行：

`Kitchen > Build Demo Scene`

## 当前操作

- 左键点击住宅或红色三维感叹号：查看该户厨房问题
- 右侧面板点击“派遣维修人员”：扣除预算并开始任务
- 中键拖动：移动社区地图
- 鼠标滚轮：缩放上帝视角

场景包含 6 户住宅，每户都展示厨房台面、水槽、灶台、烟机、橱柜等模块。红色感叹号代表待处理问题；维修人员会从中央调度中心移动到目标住宅，并依次显示“人员途中”“维修中”“已完成”。完成后感叹号消失，居民满意度提升。
